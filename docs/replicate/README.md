# Replicating this setup

These docs are for other people (and their Hermes agents) who want to run a setup like this one on their own hardware. Nothing here is specific to this homelab's hosts, accounts or people. Swap in your own values wherever an example appears.

| Doc | What it covers |
| --- | --- |
| [claude-subscription-provider.md](claude-subscription-provider.md) | Running Hermes' main model on a Claude Pro/Max subscription through the official Claude Code CLI |
| AGENT-SETUP.md (planned) | The full stack: Proxmox token and pool, agent and Logseq LXCs, Hermes install, Telegram, backups. Its provider step links to the doc above. |

Each doc is written so an agent can follow it directly. Steps that need a human (browser logins, pasting secrets, approving changes) are marked **[Operator]**.
